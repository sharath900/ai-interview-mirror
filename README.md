# AI Interview Mirror

AI Interview Mirror is an AI-powered learning and placement preparation platform built with Django.  
It helps students prepare for resumes, mock interviews, project defense, and placement readiness.

## Features

- User registration and login
- Google OAuth login
- Professional dashboard
- AI resume analyzer
- Resume-based interview practice
- Mock interview practice
- Project defense practice
- Interview history
- Resume history
- Project defense history
- Profile page with Google account details
- Privacy center
- PostgreSQL database integration

## Tech Stack

- Frontend: HTML, CSS, Bootstrap 5
- Backend: Django
- Database: PostgreSQL
- Authentication: Django Auth, Google OAuth, Django Allauth
- AI: Gemini API
- Static Files: WhiteNoise
- Deployment Ready: Render

## Project Purpose

This project is designed for engineering students who want to improve their placement preparation.  
Students can upload resumes, receive AI feedback, practice interview questions, and prepare project explanations.

## Main Modules

### Resume Analyzer
Upload a resume PDF and get AI feedback about skills, weak areas, missing details, and possible interview questions.

### Mock Interview
Practice interview questions based on role, skills, difficulty level, and interview type.

### Project Defense
Enter project title, technologies, and description. The AI asks deep project-based questions.

### Dashboard
Track preparation activities and access all major tools from one place.
